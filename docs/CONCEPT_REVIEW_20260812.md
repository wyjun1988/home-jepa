# 컨셉·JEPA 논리·성능 상한 검토 (2026-08-12)

사용자 지시: "컨셉 문제 없나, 성능 올릴 방안, JEPA 학습의 논리적 불일치 자세히".
주장이 아니라 계측으로 답한다. 신규 계측 3종을 v5 데이터에서 수행.

## 1. 계측이 준 두 개의 큰 답

### 1.1 동거인 층의 성능은 "부족"이 아니라 정보 상한 근접이다

훈련셋 GT 이동에서 사전지식 오라클을 추정하고 **완벽 게이트를 가정**(질의가 moved 임을 알려줌)한
상한 vs 실제 모델:

| | top-1 | top-2 |
|---|---|---|
| 오라클 P(dst\|cls) | 0.198 | 0.370 |
| 오라클 P(dst\|cls,src) | **0.218** | 0.371 |
| 오라클 P(dst\|cls,src,3h시간대) | 0.207 | 0.347 (희소성으로 오히려 하락) |
| **실제 모델(게이트도 스스로)** | 0.146~0.183 | **0.40~0.42** |

- top-1: 모델은 상한의 **84%**에 도달해 있다. 남은 헤드룸 ≈ 3.5pt.
- top-2: 모델이 **오라클을 이미 초과** — 부재증거·glance 로 사전지식 이상을 뽑고 있다는 뜻.
- 시간대 조건화는 이 규모에서 이득이 없다(희소성).

**결론**: 동거인-moved 0.15~0.18 은 모델 실패가 아니다. 이 층에서 관측된 이동은 정의상 없고
(아래 1.2), 남는 것은 사전지식+부재증거뿐이라 **상한 자체가 ~0.22** 다. 큰 개선은 모델링이
아니라 **증거 채널 추가**(L2 사람-소지, 더 긴 로그)나 세계 동역학 강화에서만 나온다.

### 1.2 컨셉 결함: 층화 정의가 "연관 능력"을 구조적으로 측정 불가로 만든다

moved 의 정의 = "사용자의 마지막 목격 이후 이동". 그런데 이동이 **관측되면**(새 위치에서
다시 봄) 마지막 목격이 갱신되어 그 질의는 **stayed 로 재분류**된다. 따라서:

- **moved ≡ 관측되지 않은 이동** ≡ 직접 증거가 없는 케이스 (P9 에서 positive-true 0건의 진짜 이유)
- 사용자가 처음 요구한 능력 — "여기서 사라지고 저기서 나타났으니 같은 놈이 이동" — 은
  **현재 어느 층에서도 순수하게 측정되지 않는다**. stayed 층에서는 질의 구성이 앵커를 대신
  갱신해 주므로 모델의 연관 실력이 아니라 앵커 정확도를 잰다.

**처방(벤치 확장)**: **ref-past 질의** 신설 — 참조 트랙을 의도적으로 과거 트랙으로 고정
("아침에 책상에서 본 노트북 어디?" — 이후 침실에서 목격됐어도 참조는 아침 트랙). GT 는 현재
위치이므로, 로그에 있는 재목격을 **모델이 스스로 연관해야만** 맞출 수 있다. 이것이 연관 능력의
최초의 직접 측정이 된다. 생성 변경은 질의 샘플러만 건드리면 되고 시뮬 재실행 불필요.

## 2. JEPA 학습의 논리적 불일치 — 3건 발견

### 2.1 (핵심) 티처 타깃이 주 태스크와 어긋난다 — P12 결과의 원리적 설명

스테이지1 티처 = "k번째 **다음 재관측**까지의 윈도우". 그런데 다음 재관측 위치가 현재 상태와
같은 비율을 재보니:

| | k=1 티처 위치 == 현재 상태 |
|---|---|
| 전체 | 0.876 |
| **moved 층** | **0.723** |

즉 사전학습은 moved 케이스의 **28%에서 "지금 어디"가 아닌 "다음에 어디서 발견될지"를 가르친다**
(그 사이 또 이동하는 이중 이동 — 유사라벨에서 측정했던 것과 동일한 노이즈원이 **사전학습 목적
함수 안에도** 있다). 이 한 사실이 관측된 패턴 전부와 정합한다:

- 스코어카드에서 JEPA latent 가 **nsight(다음 발견 위치)·미래 태스크에 강했던 것** — 티처가
  가르친 게 정확히 그것이므로
- P12 에서 JEPA 가 stayed(불일치 없음)에 강하고 **moved(불일치 28%)에 약했던 것**
- supervised(현재 GT 직접 학습)가 moved 에서 이긴 것

**따라서 "JEPA 사전학습이 값이 없다"(P12 판정 B)는 서술은 부정확하다. 정확히는 "현재-위치
태스크와 어긋난 목적으로 사전학습했고, 그 목적(다음 발견)에는 값이 있다".** 검증 가능한 예측
두 개를 남긴다: ① 시뮬 특권으로 티처를 '이동 미개입 재목격'으로 필터하면(불일치 0.72→1.0)
moved 격차가 줄어야 한다 ② nsight 헤드라인 태스크에서는 JEPA 가 이겨야 한다.

### 2.2 aug(접미사 절단)와 glance 피처의 누수

aug 는 질의 물체의 최근 목격 이벤트를 윈도우·loc_feat·hist 에서 숨기지만, **glance 유래
피처(_glance_feat, _absence_at)는 excl 을 받지 않아** 숨긴 목격의 흔적(해당 클래스의 조합
출현·f_aff·f_miss)이 그대로 노출된다. s1 은 aug 0.3 으로 돌므로 사전학습 질의의 30%에서
"가려진 정답의 부분 단서"가 피처로 샌다 → 모델이 이벤트 윈도우 대신 glance 피처를 과신하는
쪽으로 학습될 수 있다. **수정: aug 사본에서는 glance 유래 피처를 0 으로**(일관된 무정보)가
간단하고 안전하다.

### 2.3 베이스라인 정보 식단 불일치 (비교 공정성)

baselines.py 는 여전히 **인스턴스 id 기반**(pos_runs[e["obj"]])이다. §11.1-⑥에서 "베이스라인도
같은 식단으로"라 계획했으나 미구현. noid 모델 vs id 베이스라인 비교는 **모델에 불리한 보수적
비교**라 기존 결론의 방향은 안전하지만(모델이 특권 베이스라인과 동률/우위), 문서에 명시해야
하고 공정판(참조트랙 기준 last_known)을 만들어야 한다.

## 3. 성능을 올릴 방안 — 계측 근거 순위

| 순위 | 방안 | 근거·기대 |
|---|---|---|
| 1 | **티처 정합 실험**: s1 티처를 '이동 미개입 재목격'으로 필터(시뮬 특권) 후 JEPA 재판정 | §2.1 — P12 를 뒤집을 수 있는 유일한 원리적 후보. 예측이 명확해 반증 가능 |
| 2 | **ref-past 질의 신설** | §1.2 — 연관 능력의 최초 직접 측정. 벤치의 의미를 사용자 요구에 재정렬 |
| 3 | **aug-glance 누수 수정** | §2.2 — s1 질의 30% 오염 제거 |
| 4 | 어트리뷰트 목적지-전용 연결 (P12 큐) | 방내 +14%·자가 +8% 이득만 취하기 |
| 5 | 증거 채널: L2 사람-소지 관측, 동거인 활동 컨텍스트 | §1.1 — 상한 자체(0.22)를 올리는 유일한 길. L1 계측상 관측가능 30%가 한도 |
| 6 | 시드 앙상블(2–3개) + P12 시드 반복 | 관례상 +1~2pt, 판정 B 확정 |
| 7 | 스케일(집 600→2k, d 128→256) + Qwen 팩 다양화 | 미측정 축 — 스케일링 곡선 1회 측정 가치 |
| 8 | 베이스라인 noid 식단 통일 | §2.3 — 공정성, 성능 아님 |

하지 말 것(계측이 기각): 동거인 층을 시간대 조건화로 공략(§1.1 — 희소성으로 역효과),
동거인 층 자체를 모델링으로 밀어올리기(상한까지 3.5pt 뿐).

## 4. 요약

- **컨셉은 성립하나 두 곳이 어긋나 있다**: 층화 정의가 연관 능력을 못 재고(ref-past 로 해결),
  가장 어려운 층의 낮은 수치는 실패가 아니라 상한 근접이다(문서에 상한 병기 필요).
- **JEPA 는 "무가치"가 아니라 "목적 불일치"**였다 — 티처가 현재가 아닌 다음-발견을 가르쳤다는
  것이 계측으로 확인됐고(moved 28% 불일치), 정합 필터라는 반증 가능한 다음 실험이 있다.
- 성능의 큰 덩어리는 모델이 아니라 **측정(ref-past)·목적(티처 정합)·증거(L2)·데이터(스케일)**에 있다.
