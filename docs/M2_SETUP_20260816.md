## 🪤 랩톱 절전 함정 (2026-09-05 실측으로 적발)

**장시간 학습은 반드시 `caffeinate -ims` 로 감싼다.** 안 그러면 조용히 20배 느려진다.

증상: P14 시드 매트릭스가 5시간 경과했는데 **누적 CPU 시간은 6.5분**(가동률 5%). 로그도
멈춘 것처럼 보이지만 프로세스는 살아 있다. `pmset -g log` 에 `Entering Sleep state due to
Maintenance Sleep` + DarkWake 가 반복 기록된다 — 이 맥북은 시스템 절전이 **1분**이라
학습 중에도 잠들고, DarkWake 짬에만 조금씩 돈다.

진단법 (프로세스가 죽었는지 잠들었는지 구분):
```bash
P=$(pgrep -f train_jepa | head -1); t1=$(ps -o time= -p $P); sleep 30; t2=$(ps -o time= -p $P)
# 30초 동안 CPU 시간이 ~30초 늘면 정상, 1~2초면 절전에 먹히는 중
```
`%CPU` 컬럼만 보면 착각한다 — **경과시간 대비 누적 CPU 시간(TIME)** 이 판별 지표다.

조치: `nohup caffeinate -ims bash scripts/xxx.sh &` (i=유휴절전, m=디스크절전, s=AC 시스템절전).
적용 후 동일 측정에서 30초/30초 = 100%. 시스템 pmset 설정은 건드리지 않는다(잡 범위로 한정).
