| | iMac (구) | **M2 Max (현)** |

## 이주 중 고친 것 — torch 2.6+ 호환

`torch.load` 의 `weights_only` 기본값이 2.6 에서 True 로 바뀌어, args 딕셔너리를 담은 우리
체크포인트가 **전부 로드 실패**한다. 10개 호출 전부에 `weights_only=False` 를 명시했다.
(우리 체크포인트는 자기 생성물이므로 안전.)
