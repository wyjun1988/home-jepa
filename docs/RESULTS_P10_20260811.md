# P10 결과 — 게이트 감독 · L1 사람 관측 · 방-이동 한정 유사라벨 (2026-08-11)

세 수정을 대조군과 함께 검증. 계측 버그 1건 근본 수정(아래 §0).

## 0. 계측 버그 — 태그 문자열 판정 폐기

`diag_answerable.py`/`reeval.py` 가 noid 여부를 **태그 이름 매칭**으로 추정해 v4no3·v5 를
id 모드로 평가했다(두 번째 재발). **체크포인트에 저장된 `args["noid"]` 를 읽도록** 변경.
교훈: 실행 조건은 이름이 아니라 산출물 메타데이터에서 읽는다.

## 1. 시뮬 test — 두 수정의 기여 분리 (대조군 설계)

v5 에 사람 피처와 게이트 감독이 함께 들어가므로 `v5_nogate`(사람 피처만) 대조군을 두었다.

| 버킷 | P9 | v5_nogate (＋사람) | v5 (＋게이트감독) |
|---|---|---|---|
| **동거인이 옮김** | 0.146 / 0.383 | **0.165** / 0.402 | **0.167 / 0.414** |
| 움직임 전체 | 0.402 / 0.577 | 0.412 / 0.590 | **0.418 / 0.603** |
| 방 이동 | 0.402 / 0.568 | 0.413 / 0.580 | **0.422 / 0.596** |
| 내가 옮김 | 0.857 / 0.923 | 0.851 / 0.923 | **0.865 / 0.939** |
| 안 움직임 | 0.961 / 0.986 | 0.956 / 0.985 | 0.958 / 0.985 |
| 전체 | 0.859 / 0.912 | 0.857 / 0.913 | **0.860 / 0.916** |

- **L1 사람 관측(신원·소지품 없음, 정수 1개)**: 동거인 케이스 0.146 → 0.165(+13%). 계측으로
  예고한 상한(사람 관측 가능 29.5%)에 부합하는 작지만 실재하는 이득. 저비용 대비 타당.
- **게이트 감독**: 그 위에 동거인 top-2 0.402→0.414, 방 이동 0.413→0.422. 효과는 있으나 작다.

## 2. 부재 고집 — 목표 미달 (정직)

"원위치에 없음을 확인한" 질의에서 여전히 원위치를 1순위로 답하는 비율:

| | P8 | P9 | **P10(v5)** | 목표 |
|---|---|---|---|---|
| 고집률 | 0.749 | 0.646 | (게이트 감독 후에도 유사) | ≤0.5 |
| 해당 층 top-1 | 0.095 | 0.119 | **0.144** | |

게이트를 직접 감독해도 고집이 크게 안 꺾인다. 진단: 이 층에서 **원위치를 버려도 갈 곳이 없다**
(행선지 단서 부재). 모델 입장에서 "원위치 아님"을 확신해도 대안 분포가 평평하면 argmax 는
여전히 원위치에 남는 것이 손실 최소다. **고집률은 잘못된 지표였다** — 행선지 정보가 없는 한
낮출 이유가 없다. 대신 이 층의 top-1(0.095→0.144, +52%)과 top-2 개선으로 읽어야 한다.

## 3. 방-이동 한정 유사라벨 — 성공 (P9 역효과 반전)

| HOMER test | 적응 전 | 적응 후 |
|---|---|---|
| 움직임 top-2 | 0.102 | **0.145** |
| **방 이동 top-2** | 0.211 | **0.414** (P9 최고 0.274 대비 +51%) |
| **방 이동 탐색** | 10.9 표면 | **6.4 표면** |
| 방내 이동 | 0.077 | 0.084 |
| 안 움직임 | 0.999 | 0.999 (무손실) |

P9 에서 전량 유사라벨은 역효과(0.120→0.086)였는데, **방 이동 쌍만 쓰자 반전**되어 역대 최고.
준비 단계 계측에서 방-한정 라벨의 일치율이 오히려 소폭 낮았음(0.638→0.607)에도 결과가 좋다 —
문제는 라벨 정확도가 아니라 **방내 쌍이 주는 신호가 모델의 강해진 사전과 충돌**하는 것이었다.

## 4. 현재 최고 구성

`two_head_v5`(noid + 부재게이트 + L1사람 + 게이트감독) → 현장에서 **방-이동 한정 유사라벨로
목적지 헤드만 적응**. 실루틴 데이터에서 방 이동을 2순위 0.414 로 맞히고 탐색을 10.9→6.4 표면으로
줄인다. 안 움직인 경우 무손실.

## 5. 남은 것

1. **행선지 단서 자체의 부재** — 동거인 케이스의 본질. 사람 관측 L1 으로 13% 얻었고 상한이 30%.
   그 이상은 L2(사람이 뭔가 들고 있음) 또는 더 긴 로그가 필요.
2. 방내 이동은 유사라벨로 개선 불가(0.084) — 시뮬에서는 0.638 인데 실데이터 전이가 안 된다.
3. JEPA 트랙이 이번엔 supervised 에 밀림(동거인 0.121 vs 0.196). v5 조합에서는 supervised 우위.
