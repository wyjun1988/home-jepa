# P12 결과 — 조합 어트리뷰트 ON/OFF · JEPA 트랙 최종 판정 (2026-08-12)

두 미결을 동시에 판정: (a) 위치별 조합 어트리뷰트(`--room-feats`)가 값을 하는가,
(b) 조건을 맞춘 상태에서 JEPA 사전학습이 값을 하는가. 6개 모델을 같은 v5 데이터·같은 보조신호로 비교.

배경: P11 에서 두 침묵 결함을 발견했다 — ① JEPA stage-2 가 보조신호(aux+gate)를 못 받고 있었고
② `room_feats` 플래그가 꺼져 있어 **위치별 어트리뷰트 8종이 아예 모델에 안 들어가고 있었다**.
둘 다 고친 뒤의 결과가 아래다.

## 2. 판정 A — 조합 어트리뷰트: **이동에는 도움, 전체에는 손해**

`room_feats` ON 은 일관된 트레이드오프를 만든다(supervised_rf vs supervised OFF):
- 이득: 방내 이동 0.397→**0.454**(+14%), 내가 옮김 0.865→**0.931**(+8%), 움직임 전체 0.418→0.429
- 손실: **안 움직임 0.958→0.927**, 전체 NLL 0.606→0.649

원인: 위치별 부재·조합 신호가 위치 헤드에는 유용하지만 **게이트로도 흘러 "뭔가 바뀌었다"를 과다
판정**한다. 질의의 82%가 stayed 이므로 이 손실이 이득을 덮는다. P8 적응 실패(오버샘플이 게이트
기저율을 파괴)와 정확히 같은 구조.

**조치 방향(미실행)**: 어트리뷰트를 목적지 경로에만 연결하고 게이트로 가는 그래디언트를 차단.
그러면 방내 이동·자가이동 이득만 취하고 stayed 손실을 피한다. P8 에서 같은 처방(`--dest-only`)이
통했다.

## 3. 판정 B — JEPA 트랙: **사전학습은 값을 하지 않는다 (확정)**

조건을 완전히 맞춘 3자 비교에서 **랜덤 초기화가 사전학습을 이긴다.** 두 설정 모두에서 재현:

| | 사전학습(ft) | 랜덤초기화(scr) | 차이 |
|---|---|---|---|
| ON: 움직임 / 동거인 / NLL | 0.400 / 0.146 / 0.592 | **0.448 / 0.183 / 0.651** | scr 우세(NLL 만 ft) |
| OFF: 움직임 / 동거인 / NLL | 0.361 / 0.122 / 0.624 | **0.403 / 0.152 / 0.591** | scr 전면 우세 |

사전학습이 이기는 유일한 축은 **안 움직임/NLL**(0.961 vs 0.923) — 즉 latent 가 "안정성" 판단은
돕지만 **이동 케이스의 목적지 추론은 오히려 방해**한다. 이 프로젝트의 목표가 이동 케이스이므로
**Track J 는 주력에서 내린다.**

### 이 판정이 이전 결론을 어떻게 바꾸는가 (정직하게)

P3–P8 에서 JEPA 우위로 보고한 결과들(P4 전이 우위, P5 스코어카드, P7·P8 연관 능력)은
**JEPA 가 보조신호를 못 받는 불리한 조건에서 나온 것**이라 방향이 반대였다 — 즉 그때 이겼던 것은
더 강한 결론이다. 그러나 조건을 맞추자 **같은 우위가 재현되지 않았다.** 두 사실을 종합하면:
"JEPA 사전학습의 이득으로 보였던 것의 상당 부분은 보조신호 부재를 사전학습이 부분적으로
보상한 것"이라는 설명이 가장 단순하다. **latent 사전학습 자체의 순이득은 이 규모/난이도에서
확인되지 않는다.**

남는 가치: frozen latent 멀티태스크 스코어카드(P5 §4)는 여전히 유효하다 — 하나의 표현이 7개
다운스트림을 받친다는 결과는 사전학습 방식과 독립이며, 랜덤초기화 트렁크로 재측정할 가치가 있다.

## 4. HOMER 전이 (supervised_rf)

| | zero-shot | 적응 후(+recal) |
|---|---|---|
| 전체 top-2 | 0.914 | 0.912 |
| **방 이동** | 0.263 | **0.330** (탐색 14.2→8.8 표면) |

방 이동은 적응이 계속 이득(+25%), 방내는 계속 손해 — P10 과 같은 패턴. 다만 P10 의
`two_head_v5`(어트리뷰트 OFF) 조합이 방 이동 0.414 로 더 좋았다: **실데이터 전이에서도
어트리뷰트 ON 은 손해.**

## 5. 결론 — 현재 최고 구성

**`two_head_v5`(어트리뷰트 OFF, 게이트 감독 ON, noid, L1 사람) + 현장 방-이동 한정 유사라벨 적응.**
HOMER 방 이동 top-2 0.414 / 탐색 6.4 표면. P12 의 두 후보(어트리뷰트 ON, JEPA 사전학습)는
모두 이 구성을 넘지 못했다.
