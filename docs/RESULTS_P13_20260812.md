## 3. 판정 (시드 0)

- **예측의 방향은 맞았다**: align > base 가 moved(+0.9pt)·ref-past 연관(+2.0pt)에서 일관 —
  티처 불일치는 실제로 해를 끼치고 있었다.
- **그러나 크기가 부족하다**: align 조차 scr(랜덤초기화)를 못 넘는다(moved −2.7pt, 동거인 −3.4pt).
  즉 티처 불일치는 원인의 **일부**였고, 그걸 제거해도 사전학습 자체가 이 규모·태스크에서
  이득으로 전환되지 않는다.
- 일관 재현되는 사전학습의 유일한 이득 = stayed/안정성(0.966~0.968, 전 실험 공통).
- **Track J 종결이 더 굳어짐** (최종 확정은 4090 시드 1·2 — 런북 Job1). supervised 가 모든
  목표 지표에서 여전히 최고.
