## 0. "0.28이면 찍은 거 아냐?" — 찍기 기준선과 태스크 구조 (diag_pattern.py)

test 집은 방 5–8개(중앙값 7). moved 질의에서의 찍기/휴리스틱 수준:

| 추측 방식 | moved 전체 | 동거인-moved |
|---|---|---|
| 균등 무작위 | 0.139 | 0.139 |
| 앵커 제외 무작위 | 0.162 | 0.162 |
| (이동을 안다고 가정 시) 물체의 지정석(home room) | 0.429 | 0.453 |
| (〃) train 적합 P(목적지타입\|클래스,출발타입) 최빈값 | 0.486 | **0.508** |

두 가지 함의:
1. **top-1로 moved 서브셋을 읽으면 구조적으로 왜곡된다.** stayed 기저율이 78%라, 보정된 모델은 이동 확신이 낮은 한 앵커를 1순위로 두는 게 합리적이고, 따라서 moved 서브셋 top-1은 "이동을 확신한 경우"만 세는 지표가 된다. **제품 시나리오("일단 마지막 본 곳 확인, 없으면 다음 후보")와 일치하는 렌즈는 top-2와 기대 탐색 방 수다.**
2. **데이터에는 강한 패턴이 실재한다** — 목적지는 무작위가 아니다: P(최빈 목적지타입|클래스,출발타입) 중앙값 **0.49** (p25 0.39 / p75 0.62). 생성기 구조(활동 기반 fetch, 지정석 복귀 45%, 페르소나 tidiness)가 만든 학습 가능한 규칙성.

## 2. 판정

1. **"찍기" 반박**: 동거인-moved top-2에서 학습 모델 0.62–0.64 vs 최고 비학습 0.283 — **2.3배**. markov의 2순위(희석된 전이행렬)는 형편없어서 "휴리스틱도 top-2면 비슷하지 않냐"는 가설은 기각. 탐색 방 수로는 3.3방 → 2.5방.
2. **이벤트 히스토리의 가치 확정**: 동거인-moved top-2, 이벤트 있음 0.638 vs 어트리뷰트만 0.567 vs 비학습 0.283. 층이 셋으로 분리된다: 패턴 prior(어트리뷰트로 흡수) + 로그 문맥(이벤트만 주는 것). 4D 관측 로그 입력이라는 프로젝트 전제 성립.
3. **JEPA 사전학습이 값을 한다 (1차 확인)**: 동일 아키텍처·동일 예산에서 jepa_ft가 jepa_scratch를 전 지표에서 이김 (NLL 0.506 vs 0.522, 동거인 top-2 0.620 vs 0.598, all-t1 0.847 vs 0.844). **stage 1은 라벨 0개**(타깃=다음 재관측까지의 로그) — 실데이터 전이의 근거. 단 flat_v2 supervised와는 사실상 동률(우열 지표별 혼재)이라 "이긴다"가 아니라 "라벨 없이 따라잡는다"가 현재 클레임. 동결 probe(0.830)만으로는 부족 — 파인튜닝 필요.
4. **구조 실험 결론**: two_head(게이트 분해)는 전체 top-1 최고(0.848)지만 동거인 칸에서 flat에 밀림(0.613 vs 0.638). 명시적 방 피처(flat_v3 0.828)는 이벤트와 겹치면 해로움 — v0의 최소 설계(flat + 앵커 어트리뷰트 + 예약 윈도우)가 최종 승자. 시드 재현성: flat_v2 s0/s1 완전 일치 수준.
5. **남은 헤드룸**: 이동을 안다고 가정한 조건부 최빈 추측이 0.508(top-1)인데 모델의 조건부 활용은 아직 그에 못 미침 — 게이트 캘리브레이션과 목적지 헤드에 개선 여지.
