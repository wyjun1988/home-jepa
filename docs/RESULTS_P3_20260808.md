# P3 결과 — 월드모델 스코어카드 · 이벤트-지평 목표 · 무라벨 스케일링 (2026-08-08)

컨셉(사용자 정의): **latent 가 월드모델 모먼트를 가져서 여러 다운스트림(현재/미래 미관측 추정)을 받친다.**
이에 맞춰 P3 는 (A) frozen 트렁크 멀티태스크 probe 스코어카드, (B) 사전학습 목표 개선
(이벤트-지평 k∈{1,2,4} + 구조화 마스킹), (C) 무라벨 5배 스케일링을 검증했다.
데이터: 감사 PASS 판(train 1000 / test 80) + 무라벨 풀 5000집(생성 후 샘플 감사 PASS).

## 1. 설계 변경 (사용자 지시 반영)

- **지평은 시간이 아니라 이벤트 단위** — 밤 6시간(정보 0)과 청소 5분(이동 10건)을 같은 지평으로
  묶는 시계 지평 대신, "그 물체의 k번째 다음 목격"(k∈{1,2,4})을 티처 타깃으로. predictor 는
  horizon 임베딩 조건.
- **마스킹도 랜덤 금지** — i.i.d. 이벤트 드롭이 아니라 **질의 물체의 최근 목격 m∈{1,2,4}개 접미사
  절단**(p_det<1 이라 분포 내 시나리오; SELF 이벤트는 유지; 앵커·부정증거 피처를 마스크 기준으로
  재계산). 티처는 특권 유지(마스크 없는 컨텍스트 + 공개 시점까지).
- 다운스트림 미래 태스크도 이벤트 단위로 교체: **nmove**(다음 이동의 목적지), **nsight**(다음 발견
  위치). 기존 mv6h 는 random 트렁크도 풀려서 폐기. 시계 지평(+1h/+6h)은 참조로 유지.

## 4. 판정 (정직하게)

1. **JEPA 사전학습 = 유효한 초기화.** 최종 최강 모델은 jepa_v3_ft(신목표 사전학습→파인튜닝,
   0.849/0.5038)이고, 동일 아키텍처 랜덤 초기화 대비 전 지표 우위(동거인 0.218→0.243). stage 1 은
   라벨 0. — **성립.**
2. **JEPA latent = supervised 를 능가하는 범용 월드모델 표현?** 이 스케일에서는 **불성립.**
   supervised 단일태스크 트렁크가 5개 probe 태스크 전부에서 우위 — 학습한 적 없는 미래 태스크
   포함. 격차는 지평이 멀수록 좁아지는 추세(현재 -7.6pt → +6h -2.3pt)는 유지되나 역전은 없음.
3. **이벤트-지평 목표 효과**: probe 수준에서 미미(nmove +1.0pt, nsight +0.4pt, 시계 지평은 소폭
   하락). 파인튜닝 수준에서는 최고 기록 갱신(0.5058→0.5038)이지만 오차 범위급.
4. **무라벨 5배 스케일 효과: 0.** 5x vs 1x 파인튜닝 구분 불가(0.848 vs 0.849), probe 도 ±1pt.
5. **원인 진단 — 천장 포화.** 강한 모델 전부가 top-1 0.844–0.849 / NLL 0.504–0.515 에 수렴.
   이 시뮬레이터 구성(방 5–8, 루틴 확률성)의 비가약 불확실성과 0.7–1.5M 모델 용량에서
   1000집 라벨이면 이미 충분 — 표현의 우열이 드러날 여지가 없다.
   또 하나: **시뮬 비교는 구조적으로 JEPA 에 불리**하다. supervised 는 시뮬에서 공짜 완전 라벨을
   받는데, 실환경에는 그런 라벨이 존재하지 않는다. JEPA 의 실전 우위(재관측=지연 라벨만으로 학습)는
   라벨이 희소한 조건에서만 드러나며, 라벨 10% probe 축에서 JEPA 열화가 더 작았던 것이 그 단서.

## 5. 다음 갈림길 (P4 후보)

1. **천장 올리기**: receptacle 계층 재도입(사용자가 v0 에서 보류), 방 수·동거인 수·루틴 다양성 확대,
   관측 노이즈 — 표현이 변별되는 난이도로.
2. **실데이터 전이 (본판정)**: ADT 스티칭 zero-shot + HOMER+ held-out. 라벨 없는 실로그에서
   재관측-지연-라벨로 학습 가능한 것은 JEPA 뿐 — supervised 는 출전 자체가 불가한 무대.
3. 모델 스케일업(RunPod/4090) — 데이터가 아니라 용량이 병목일 가능성 점검.
