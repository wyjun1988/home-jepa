목표(사용자): P4 계속 → 실데이터 확인 후 천장 올리기 → 부족한 부분 확인·보완 → latent 다운스트림 후보 선별·테스트.

상태공간을 방(5–8)→receptacle(8–30, MAX 32)로. moved 질의 25.3%(방내 15%p+방간). v0의 0.844–0.849 정체가 풀렸다:

- **JEPA 사전학습→파인튜닝이 다시 종합 1위** (NLL 0.748), scratch 대비 일관 우위.
- v0 결론 반전 2건: 32-way 에서는 **two_head(게이트)가 flat 을 이긴다**(0.812 vs 0.802 — 위치 공간이 커지면 분해가 유효); 단 동거인-moved top-1 은 flat 이 우위 — 트레이드오프 지속.
- 학습기 발견 버그 1건: train_jepa 의 평가 함수가 v0 잔재(32-wide 분포를 방 id 에 오대응) — 수정·재평가로 해결. 체크포인트는 무결.

## 2. ADT 실센서 — zero-shot 안착 (파이프라인 검증 완수)

36개 2인 시퀀스(각 ~95s), 모캡 GT + 프레임별 실제 가시성(비전 모델 0), 최근접-가구 귀속, 감사 PASS(변환기 초기틱 버그 1건을 감사가 적발→수정). 1,122질의(moved 2.4% — 짧은 지평 한계).

- **게이트형 v1 모델 3종 전부 zero-shot 으로 last_known 동률(0.976)** — v0 가 HOMER 에서 보인 붕괴 없음. Δt 조건 게이트·receptacle 어휘가 실센서 로그에 그대로 이식됨.
- flat_r1 만 과이동(0.898) — flat 구조의 고질.
- moved 층(n=27)은 방향성만: 탐색 9.0(jepa_ft) vs 11.0(베이스라인).

## 3. HOMER+ 가구수준 전이 — 남은 갭의 정체 확정

가구 노드 1:1 재변환: 15,200질의, moved 9.9%(방수준 5.3%의 약 2배; moved_within 이 80%).

- **게이트형 모델 zero-shot 붕괴 없음**(0.889–0.890 vs last_known 0.901; flat 0.163 붕괴), 재캘리브레이션으로 전부 0.901 복원.
- **그러나 moved 층의 목적지 지식이 가구 수준에서는 전이되지 않음**: moved top-2 최고 0.095–0.123 (시뮬 내 0.52 대비). 방 수준(v0 실험)에서 0.64 가 전이됐던 것과 대조.
- **진단**: 시뮬의 receptacle 전이 패턴(활동→표면 매핑, WITHIN_SHIFT 3종)이 실루틴의 가구 생활사(설거지→싱크→찬장, 식재료→조리대→식탁 체인)와 다르다. **어휘는 이식됐지만 동역학 사전이 다름** — 캘리브레이션으로 못 고치는 부분.
- **보완 방향(다음 루프)**: ① 생성기 활동-표면 체인을 HOMER 통계로 보강(라벨 불필요 — 그들의 train 스플릿 GT 는 시뮬레이터 설계 참고로만) ② **JEPA s1-continue 를 HOMER adapt 로그(195일, 라벨 0)로** — 무라벨 적응이 동역학 사전을 흡수하는지가 다음 본판정.

## 4. 다운스트림 후보 선별·테스트 — 스코어카드 v3 (frozen latent + 선형 probe, 7태스크)

**v1 에서 월드모델 클레임이 처음으로 선다**: v0 스코어카드에서는 supervised 트렁크가 전 태스크 우위였는데, receptacle 난이도 + 이벤트지평 목표에서 **JEPA frozen latent 가 현재 태스크 동률, 모든 미래 태스크와 tidy 에서 우위**(+6h +3.0pt, tidy +7.5pt). 후보 판정:

- **채택(강)**: `tidy`(어디로 치울까 — JEPA 우위 최대, 제품 직결), `+6h/+1h 위치`(미래 미관측 추정 — 컨셉 그 자체)
- **채택(중)**: `nsight`(다음 발견 위치), `misplaced`(정리 알림 — 두 트렁크 모두 유효, supervised 소폭 우위)
- **보류**: `nmove`(다음 이동 목적지) — 선형 probe 로는 전 트렁크 near-random. 비선형 헤드/파인튜닝 필요.

## 판정

1. **두 보완책은 서로 다른 축을 고친다.** 생활사 체인(v2)은 **목적지 지식**을 개선(+18% moved,
   +25% moved_room), 무라벨 적응·recal 은 **캘리브레이션**을 개선(stayed NLL 0.47→0.09–0.18).
   무라벨 적응 단독은 목적지를 못 메움(트렁크만 적응, readout 은 시뮬 동역학에 고정).
2. **실전 합성 레시피: v2 사전학습 + 로그 recal** — 전체 top-2 0.912(최고), 목적지 이득 유지,
   stayed NLL 0.089(최고). 전 베이스라인 상회.
3. **남은 열린 문제**: 방내(moved_within) 목적지 0.078 — 시뮬 내 0.5 대비 여전히 큼. 시뮬 체인을
   더 맞추는 것은 벤치마크 맞춤 위험. **다음 후보: 재관측 유사라벨로 readout 적응** — 대상 로그에서
   (질의시점, 다음 재관측이 공개한 위치) 쌍은 GT 없이 구성 가능하므로, probe/게이트를 현장에서
   라벨 프리로 미세조정하는 배포-합법 경로. 미실험.
