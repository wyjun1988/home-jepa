# P8 결과 — noid 슬랙 회수 · 유사라벨 적응 · 데이터 검증 (2026-08-10)

목표: 순서대로 진행 + 데이터 검증 + 못 푸는 것 정리·해결.

## 1. 데이터 검증에서 나온 것 (P7 결과에 영향)

### 1.1 glance 버그 — 조합 어트리뷰트가 반쯤 죽어 있었다

glance 의 물체/가구 목록이 **인스턴스가 아니라 틱 반복**을 세고 있었다(한 물체가 12틱 보이면 12번
등장). 결과: f_wit(증인 수) 12배 부풀려 상시 포화, f_miss 무분별 발화, 유사라벨의 singleton 필터가
**전부 거부(0건)** — 이 버그로 파이프라인이 조용히 비어 있던 것을 발견. 수정 후 `objs=['cup','cup','cup','phone']`
처럼 실제 인스턴스를 센다. **사용자가 제안한 조합 메커니즘은 P7 에서 열화된 상태로 평가됐다.**

### 1.2 유사라벨 품질 정량화 (GT 대조, 학습에는 미사용)

"다음 목격 위치 = 정답" 가정의 실제 신뢰도:

| | 게이트 전 | **게이트 후**(공백≤3h + 증인확인 부재) |
|---|---|---|
| 전체 일치 | 0.835 | **0.863** |
| **pseudo-moved 일치** | 0.514 | **0.638** |
| moved 표본 | 922 | 268 (엄선) |

이동 케이스의 유사라벨은 **절반만 맞는다**(이중 이동, 동클래스 타 인스턴스). 목적지 문제는
"라벨 없음"이 아니라 **"64% 신뢰도 라벨로 학습"** 문제임이 확정.

## 2. noid 슬랙 회수 — 성공 (손-사슬 앵커 + glance 수정 + 5000스텝)

자기 손으로 옮긴 것은 identity 가 물리적으로 확실 → noid 앵커가 SELF pick→drop 사슬을 따라감
(클래스+표면+시각 매칭만, id-free 유지). 시뮬 test top-1/top-2:

| bucket | P7 v4no | **P8 v4no2** | v4id2(참조) | jepa_v4no2_ft |
|---|---|---|---|---|
| moved_within | 0.046 | **0.270** (5.9배) | 0.448 | 0.305 |
| cls_single\|moved | 0.175 | **0.377** | 0.628 | **0.480** |
| cls_multi\|moved | 0.234 | **0.284** | 0.379 | 0.327 |
| 동거인-moved | 0.139 | 0.146 | 0.113 | 0.136 |
| 전체 | 0.843 | 0.847 | 0.886 | **0.858** |

- P7 최악 버킷(방내 연관 0.046)이 0.270 으로 회복 — **미해결 1건 해소.**
- **JEPA 사전학습이 noid 연관에서 계속 우위**(cls_single 0.480 vs supervised 0.377) — P7 결론 재확인.
- noid vs id 격차는 유지(0.847 vs 0.886) — 연관 프리미엄은 실재하는 난이도.

## 3. 유사라벨 readout 적응 — 목적지 벽(0.112) 돌파

세 번의 설계 수정이 필요했다. 실패도 기록한다:

| 시도 | 설계 | 결과 |
|---|---|---|
| 1차 | moved 35% 오버샘플 + 통합 손실 | **붕괴**: all t2 0.904→0.355, stayed 1.000→0.371 (기저율 13배 왜곡 → 게이트 파괴) |
| 2차 | 게이트/목적지 손실 분리 (게이트는 자연 분포) | 부분 회복 0.698, stayed 0.756 — 공유 위치임베딩 경로로 게이트 여전히 오염 |
| **3차** | **목적지 헤드만 적응, 게이트는 무라벨 recal 에 위임** | **성공** |

HOMER+ test (15.2k 질의), 3차 결과:

| | two_head_v4no2 (전→후) | jepa_v4no2_ft (전→후) |
|---|---|---|
| 전체 top-2 | 0.904 → **0.916** | 0.903 → 0.912 |
| stayed top-2 | 1.000 → **1.000 (무손실)** | 1.000 → 1.000 |
| moved top-2 | 0.051 → **0.176** (3.5배) | 0.045 → 0.135 |
| moved_within | 0.020 → **0.146** (7배) | 0.055 → 0.098 |
| moved_room | 0.189 → **0.309** | 0.000 → 0.302 |
| moved_room 탐색 | 10.88 → **8.97** | 15.05 → **7.45** |

**P6 이후 굳어 있던 목적지 벽 0.112 를 0.176 으로 넘었다** — 라벨 0, 대상 집 로그만으로.
점검 메모: 이 표의 `+recal` 은 top-2 를 바꾸지 않는다(τ 는 앵커 확률만 대체하므로 off-anchor
순위가 불변). recal 의 기여는 NLL/캘리브레이션 축에서만 유효하며, 목적지 개선분은 전적으로
유사라벨 적응의 몫이다.
배포 레시피 확정: **시뮬 사전학습 → (현장) 목적지 헤드 유사라벨 적응 + 게이트 무라벨 recal**.
원리: 조건부 P(위치|이동)은 기저율 불변이라 오버샘플이 정당하지만, 게이트는 실제 기저율을 봐야 한다.
