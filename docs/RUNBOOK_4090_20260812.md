## Job 1 — P13 판정 시드 확정 (최우선, 4암 × 시드 2개 = 8런)

JEPA 존폐 판정(P12·P13)의 시드 반복. 시드 0 은 로컬 결과를 쓴다.

```bash
for S in 1 2; do
  # (a) supervised 기준
  python scripts/train_supervised.py --data data/v5 --tag two_head_v5_s$S --model two_head \
    --noid --gate-weight 0.5 --steps 5000 --val-every 500 --seed $S
  # (b) JEPA base (누수수정 티처)
  python scripts/train_jepa.py --data data/v5 --tag jepa_v6_base_s$S --noid \
    --event-horizons --aug-gap 0.3 --s1-steps 3000 --s2-steps 0 --val-every 500 --seed $S
  python scripts/train_jepa.py --data data/v5 --tag jepa_v6_base_s${S}_ft --noid \
    --load-s1 results/jepa_jepa_v6_base_s${S}_s1.pt --no-freeze --aux-weight 0.5 --gate-weight 0.5 \
    --s2-steps 5000 --val-every 500 --seed $S
  # (c) JEPA 티처정합
  python scripts/train_jepa.py --data data/v5 --tag jepa_v6_align_s$S --noid \
    --event-horizons --aug-gap 0.3 --align-teacher --s1-steps 3000 --s2-steps 0 --val-every 500 --seed $S
  python scripts/train_jepa.py --data data/v5 --tag jepa_v6_align_s${S}_ft --noid \
    --load-s1 results/jepa_jepa_v6_align_s${S}_s1.pt --no-freeze --aux-weight 0.5 --gate-weight 0.5 \
    --s2-steps 5000 --val-every 500 --seed $S
  # (d) 랜덤초기화 대조
  python scripts/train_jepa.py --data data/v5 --tag jepa_v6_scr_s$S --noid \
    --scratch --no-freeze --aux-weight 0.5 --gate-weight 0.5 --s2-steps 5000 --val-every 500 --seed $S
done
```

판정 지표(시드 3개 평균±표준편차로): 시뮬 test `moved`·`moved_by:housemate` top-1/2 —
scr vs base vs align. **align > base 이고 align ≥ scr 이면 티처 정합 가설 채택**(JEPA 부활),
scr 우위가 유지되면 Track J 종결 확정.
