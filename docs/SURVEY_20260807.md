# Home-JEPA 자료조사 (2026-08-07)

에고센트릭(AI 안경, ~1fps) 관측 스트림으로 4D scene graph 를 유지하면서, **지금 안 보이는 물체의 현재 상태(우선은 위치)** 를 JEPA 방식 latent 예측으로 추정하는 프로젝트의 사전 조사. 5개 병렬 조사(선행연구·에고센트릭 데이터셋·시뮬레이터·JEPA 방법론·로컬 stock Graph-JEPA 코드맵)를 종합했다. 링크는 조사 시점(2026-08-07) 웹 검증 기준.

---

## 0. 한 줄 결론

**"제3자가 옮겨서 last-seen 이 틀리게 된 미관측 물체의 현재 위치"를 채점하는 공개 벤치마크는 존재하지 않는다.** 가장 가까운 정식화(SGM, ICML 2023)는 합성·기호 수준이고, 에고센트릭 계열(OSNOM/Whareformer)은 전부 "안 보는 동안 세상 정지"를 가정한다. 반면 부품(그래프 레벨 시뮬레이터 레시피, 평가 지표, 실데이터 평가셋, JEPA 설계 레시피)은 대부분 공개돼 있어 **벤치마크+방법을 우리가 조립해서 만드는 것 자체가 기여**가 된다. 2025–26 로보틱스에서 같은 문제로 수렴하는 물결(FlowMaps, PreSIST, Perpetua 등)이 있으나 공유 벤치마크가 없다 — 시기적으로 빈 슬롯이 맞다.

## 1. 태스크 정의 (요구사항 정리)

- **입력**: 과거→현재의 타임스탬프 관측 로그 = 4D scene graph 이벤트 스트림. 예: "노트북, t≤300 거실에서 관측 → t=350 거실에서 부재 확인 → t=400 방에서 관측". 현재 스냅샷이 아니라 **기록 전체**가 입력.
- **질의**: (물체 o, 현재 시각 t_now) → 미관측인 o 의 현재 위치 분포.
- **출력**: latent state 추정 (평가용 probe 가 위치로 디코딩). 위치 외 상태는 후순위.
- **학습 목표**: 개인/집 암기가 아니라 **환경 간 일반화되는 가정 내 동역학** (SGM 이 이 테제를 정량 지지: 아래 §2.1).
- **시간 범위**: 현재 상태만. 미래 예측은 확장 항목.
- **관측 주체**: AI 안경 1fps 가 1차 대상. 단, 픽셀→scene graph 지각은 별도 단계로 분리 가능(§5.3).

## 2. 선행연구 지형

### 2.1 같은 문제의 정식화 — Scene Graph Memory (가장 가까운 원조)

**"Modeling Dynamic Environments with Scene Graph Memory"** — Kurenkov et al., ICML 2023. [arXiv:2305.17537](https://arxiv.org/abs/2305.17537) · [코드](https://github.com/andreykurenkov/modeling_env_dynamics) (**GPL-3.0, 2023-05 이후 방치**) · [사이트](https://www.scenegraphmemory.com)

- 태스크 = "부분관측 동적 그래프의 링크 예측". 집/방/가구/물체 계층 그래프에서 물체가 이산 시간마다 이동하고, 에이전트는 부분 서브그래프만 관측. 관측을 Scene Graph Memory 로 누적(노드 피처: 마지막 관측 후 경과, 관측 횟수, 이동 빈도, prior 등)하고 Node Edge Predictor(NEP) 가 미관측 물체의 가구 노드 posterior 출력.
- 평가 3종: 위치 정확도 / NDCG / 탐색 행동 수.
- **핵심 수치**: NEP-HEAT **0.351** > Bayesian 0.286 > Frequentist 0.271 > priors 0.159, oracle 0.454. 100개 훈련 환경 → 100개 미지 환경 평가. **"일반 동역학 학습 > 개별 환경 베이지안 암기"의 직접 증거.**
- 데이터: 자체 "Dynamic House Simulator"(iGibson 2.0 의 그리드월드 재구현 "iGridson"). 이동 prior 는 iGibson 2.0 + ProcTHOR-10K 통계에서 카운트.
- **우리와의 차이**: (i) 기호 수준 합성 관측 — 에고센트릭 스트림 없음, (ii) 동역학이 클래스 빈도 노이즈이지 **사람 루틴이 아님**, (iii) 이산 스텝·연속 시간 질의 없음, (iv) 제3자 에이전트 모델 없음.

### 2.2 2025–26 로보틱스 물결 — semi-static 상태 추정으로 수렴 중 (공유 벤치마크 없음)

| 연구 | 내용 | 우리와의 관계 |
|---|---|---|
| [FlowMaps](https://arxiv.org/abs/2509.16398) (2025, [코드](https://github.com/Fra-Tsuna/flowmaps)) | **재배치된 물체의 목적지 분포를 flow matching 으로** — 시공간 multimodal 분포, 반복 습관 활용 | 추론 문제가 동일, 생성적 접근. 직접 경쟁 방법 |
| [Predictive Spatio-Temporal Scene Graphs](https://arxiv.org/abs/2605.00121) (2026-04) | 엣지 = Perpetua 식 베이지안 persistence 필터. 3주 실배포 검증 | belief-필터 계열 최신. 강한 클래식 베이스라인 |
| [PreSIST](https://arxiv.org/abs/2607.04057) (2026-07) | VLM 이 물체 속성→잔존(persistence) prior, persistence 필터와 융합 | "머무를 확률"만, 목적지 없음 |
| [STAR/STARBench](https://arxiv.org/abs/2511.14004) (2025-11) | "search in time(메모리 질의) vs space(이동)" 통합 루프, 벤치 포함 | 검색 정책 벤치. 상태추정 순수 벤치 아님 |
| L-DOR (IEEE TII 2026) | 사람이 옮긴 물체 재탐색용 확률 시공간 모델 | 페이월, 세부 미확인 |
| [DynamicTHOR](https://www.nature.com/articles/s41597-026-07201-7) (Sci. Data 2026) | **LLM 이 주민 루틴을 시뮬레이션**해 THOR 씬에서 물체 dynamics 생성. 50 캐릭터/100 씬, 공개 | **제3자 루틴 dynamics 데이터 기반으로 가장 가까움.** 단 내비게이션용 패키징, 위치질의 프로토콜 없음 |

클래식 계보(전부 이겨야 할 베이스라인): Persistence Filter (Rosen, ICRA 2016) → **시간감쇠 잔존 모델** (Toris & Chernova, ICRA 2017 — "마지막 목격 후 t 경과 시 그대로 있을 확률") → FreMEn (T-RO 2017, 주기성 스펙트럼) → PreSIST/Perpetua (2026).

### 2.3 에고센트릭 "what is where" 라인 — 전부 정적 세계 가정

- **OSNOM** ("Out of Sight, Not Out of Mind", [arXiv:2404.05072](https://arxiv.org/abs/2404.05072), 2024; 조사에서 ECCV 2024/3DV 2025 로 표기 엇갈림) — 화면 밖 물체 포함 전 활성 물체의 3D 위치 연속 추정 (Lift-Match-Keep). EPIC-KITCHENS 100개 장편 영상. **사라진 후 2분 시점 57~60% 정확** (베이스라인 33%/17%). **지표 설계(소실 후 Δt 별 정확도 곡선)를 가져올 것.**
- **Whareformer** (ECCV 2026, [arXiv:2607.08537](https://arxiv.org/abs/2607.08537)) — track memory 트랜스포머, SOTA. 평가 트리플렛: EPIC-KITCHENS-100 / IT3DEgo / HD-EPIC.
- **IT3DEgo** (CVPR 2024, [arXiv:2312.04117](https://arxiv.org/abs/2312.04117), **MIT, 다운로드 마찰 최소**) — AR 기기 3D 인스턴스 추적, 구간별 3D 좌표 GT.
- **공통 한계 = 우리의 빈 슬롯**: 물체는 착용자 손으로만 움직이고, 안 보는 동안 세상은 정지. "last-seen = 정답"이 성립하는 세팅이라 우리 핵심 시나리오를 채점할 수 없음.

### 2.4 어시스턴트 메모리 / QA 벤치마크 — 전부 회고형

Ego4D VQ2D/VQ3D/NLQ ("**마지막으로 본** 곳 검색"이 명시 정의), EgoTracks(안 보이면 주석 중단), OpenEQA(EM-EQA — 답이 관측 이력 안에 있음), EgoLifeQA, ReMEmbR/NaVQA, FindingDory, PersONAL — 모두 관측된 것의 검색/회상. **관측 후 제3자 이동으로 정답이 바뀐 경우를 묻는 벤치마크 없음.** (참고용: NLQ 13개 질의 템플릿, OpenEQA 의 LLM-Match 채점.)

### 2.5 매핑 시스템 — 재관측 시 업데이트만

Khronos (RSS 2024, 시공간 SLAM "4D map"), DynaMem (ICRA 2025), Lost & Found (RA-L 2025 — 에고센트릭 상호작용 관측으로 scene graph 를 6DoF 업데이트), GOAT/GOAT-Bench, Hydra/Clio. 전부 **증거가 생겨야 갱신**: 안 본 사이의 변화를 추론하지 않음. Lost & Found 는 우리 예측기의 보완 모듈(관측된 이동 반영)로 적합.

### 2.6 방법 쪽 최근접 — C-JEPA

**Causal-JEPA** (ICML 2026, [arXiv:2602.11389](https://arxiv.org/abs/2602.11389), [코드](https://github.com/galilai-group/cjepa)) — 패치가 아니라 **객체 단위 latent 를 통째로 마스킹**하고 주변 맥락에서 숨긴 객체 상태를 추론시키는 JEPA. "구조화된 부분관측을 훈련 마스크로" = 우리 목표와 동일 철학. 단 지속적 시간축·제3자 dynamics 없음. **SGM 류 데이터 + JEPA 조합은 아직 아무도 안 함** (2026-08 기준 확인).

### 3.2 시뮬레이션 (훈련 중심)

**추천 1순위 — HOMER 레시피 (Georgia Tech RAIL 계열, 전부 MIT):**
루틴/습관 분포에서 하루 일과 샘플링 → 행동 스크립트를 **VirtualHome "Evolving Graph"(렌더링 없는 순수 파이썬 그래프 전이 함수)** 로 실행 → **타임스탬프 붙은 전체 물체 배치 scene graph + 활동 라벨** 출력.
- [HOMER](https://arxiv.org/pdf/2211.15501) (CoRL 2022) → [HOMER+](https://github.com/Maithili/HOMER_PLUS) (2026-04 푸시) → [SLaTe-PRO](https://arxiv.org/pdf/2309.06252) → [ADAPT](https://arxiv.org/abs/2504.04040) → HOMER-Noise ([RO-MAN 2026](https://arxiv.org/pdf/2606.08458), 사람/애완동물/유아 교란) — **라인이 살아있음**.
- 생성기: [RoutinesDataCollection](https://github.com/Maithili/RoutinesDataCollection) + [rail_tasksim](https://github.com/GT-RAIL/rail_tasksim) (2026-03 푸시). [SpatioTemporalObjectTracking](https://github.com/Maithili/SpatioTemporalObjectTracking)(생성적 GNN)이 같은 데이터 형태로 이미 훈련한 선례.
- 우리 확장 4개: ① 다중 주민(스케줄 샘플러 병렬) ② LLM 페르소나 루틴 ([AgentSense](https://arxiv.org/pdf/2506.11773), AAAI 2026 선례) ③ SGM 식 이동 prior 랜덤화 ④ **에고센트릭 가시성 필터**(사용자 에이전트 위치·시야→관측 서브그래프 = "1fps 안경이 봤을 것").
- 속도: 그래프 레벨이라 렌더링 시뮬 대비 **2~4자릿수 빠름** (코어당 시간당 수천 일 규모 추정). 이 머신(AMD GPU 맥)에서 OmniGibson(Isaac Sim, NVIDIA 전용)은 아예 불가 — 그래프 레벨 우선의 실용적 이유이기도 함.

**대안/보조:**
- [DynamicTHOR](https://www.nature.com/articles/s41597-026-07201-7): LLM 주민 루틴 → THOR 물체 dynamics, 이미 공개. 재활용 검토 가치 (단 위치질의 프로토콜은 우리가 얹어야 함).
- AI2-THOR + [ProcTHOR-10K](https://github.com/allenai/procthor) (**Apache 코드+집 1만 채**): 렌더링 검증·지각 프론트엔드 단계의 2순위. `event.metadata` 에 containment/개폐/가시성이 다 있어 scene graph 가 공짜.
- Habitat 3.0 + PARTNR(10만 LLM 집안일 태스크, 코드 MIT / HSSD 씬 CC-BY-NC), 참고.
- 라이선스 지뢰: Watch-And-Help/NOPA CC-BY-NC-SA(방치), SGM 코드 GPL-3.0(방치 — 설계 참고만), Mini-BEHAVIOR 라이선스 파일 없음, BEHAVIOR 에셋 암호화.
- 스케줄 리얼리즘 캘리브레이션: [CASAS](https://zenodo.org/records/15708568) (실제 집 189채·18년 ambient 센서 로그) 통계 활용. HOMER+ 는 훈련에 안 쓰고 **held-out 리얼리즘 벤치**로 남기기.

### 3.3 제안 데이터 전략 (논의용)

1. **훈련**: 자체 그래프-레벨 생성기 (HOMER 레시피 + 확장 4개). 무제한 에피소드, GT 공짜, 환경 간 일반화 평가를 위한 환경 분리 자유.
2. **평가(합성)**: held-out 환경 + HOMER+ 원본 + (선택) DynamicTHOR 위에 질의 프로토콜.
3. **평가(실)**: ADT 2인 시퀀스(모캡 GT) 스티칭 → zero-shot 전이. 보조로 HD-EPIC/IT3DEgo (정적 가정 세팅에서 last-seen 대비 손해 없음 확인용).
4. **(야심 옵션)** EgoLife 재주석으로 "EgoLife-Relocations" 실벤치마크 제작 — 최초 기여가 되지만 주석 비용 있음.

## 4. 방법 (JEPA)

### 4.1 설계 레시피 — 검증된 부품 조합

- **인코더**: 관측 이벤트 로그의 temporal graph 인코더. TGAT 식 함수형 시간 인코딩([arXiv:2002.07962](https://arxiv.org/abs/2002.07962)); TGN 식 노드 메모리(= 노드별 belief latent)는 옵션. 참고로 TGB 벤치 교훈: **단순 휴리스틱이 의외로 강함** — 베이스라인 엄격히.
- **마스킹**: C-JEPA 철학 — **물체 노드를 시간 구간째 마스킹**. 우리 데이터엔 "진짜 미관측"이 자연 발생하므로 훈련 마스크 = 실제 관측 결손 분포와 정렬 가능. Brain-JEPA ([NeurIPS 2024](https://arxiv.org/abs/2409.19407)) 의 타깃 분류(Cross-ROI/Cross-Time/**Double-Cross** = 안 본 노드의 안 본 시각)를 그대로 이식. 미관측 구간 길이 커리큘럼 (A-JEPA/NodeJEPA 선례).
- **타깃 인코더**: EMA, 특권 정보 열람 — 시뮬에서는 full state, 실데이터에서는 **미래 재관측을 포함한 로그** (재관측 = 지연된 라벨. GT 없는 실로그에서도 학습 신호가 생기는 지점 — JEPA 정당화의 핵심).
- **predictor**: 질의 토큰 (물체 identity, Δt=미관측 경과, 구조 기술자) 조건 cross-attention (I-JEPA 위치토큰의 일반화; [NodeJEPA](https://arxiv.org/abs/2608.04381) 2026-08 이 그래프에서 검증). **롤아웃 금지, Δt 직접 조건 예측** (장기 미관측에서 autoregressive drift 회피).
- **붕괴 방지**: EMA + stop-grad + 비대칭 predictor + VICReg 분산·공분산 (stock 코드 그대로 이식) + imputation anchor. 대안으로 LeJEPA/SIGReg ([arXiv:2511.08544](https://arxiv.org/abs/2511.08544), 그래프 미검증).
- **사전 참고**: [jepa-wms](https://github.com/facebookresearch/jepa-wms) ("What Drives Success…", TMLR 2026) — JEPA 월드모델 설계 유일한 체계적 ablation. 착수 전 정독 대상.

### 4.2 Multimodality — 최대 난점

미관측 물체의 현재 위치 posterior 는 본질적으로 **이산 multimodal** {부엌 조리대, 식기세척기, 식탁, …}. 결정론적 latent 회귀의 최적해는 조건부 평균 = 어느 모드도 아님. 더 나쁜 것: JEPA 의 implicit bias ([NeurIPS 2024 이론](https://arxiv.org/abs/2407.03475))는 **예측 불가능한 변수를 표현에서 버리는** 쪽 — 제3자 이동으로 예측이 어려운 위치가 "불확실"이 아니라 "누락"될 위험.

2025–26 처방 옵션:
1. **범주형/에너지 readout probe** — 위치 vocabulary 가 이산·열거 가능하므로 후보 위치를 스코어링. 가장 단순, 우리 세팅에 자연스러움.
2. **Branch-JEPA** ([arXiv:2607.05238](https://arxiv.org/abs/2607.05238), 2026-07) — K개 latent successor + winner-take-all/Energy Score. "latent 에서 분기 > 디코더에서만 분기" 정량 검증. 직접 이식 후보.
3. **Discrete JEPA** ([arXiv:2506.14373](https://arxiv.org/abs/2506.14373)) — 코드북 latent, 범주 분포 자연 표현 + 장기 drift 저항.
4. 단일 가우시안 변분 헤드는 이산 모드 분리 불가로 문서화됨 (기각).
- 평가도 top-1 만 보면 안 됨: **proper scoring rule (Brier/Energy Score) 필수** (Branch-JEPA 교훈).

긍정 증거: V-JEPA 의 intuitive physics 결과 ([arXiv:2502.11831](https://arxiv.org/pdf/2502.11831)) — JEPA latent 는 가림막 뒤 물체 기대(object permanence)를 zero-shot 으로 이미 담는다. PLDM ([arXiv:2502.14819](https://arxiv.org/abs/2502.14819)) — 수동적·저품질 로그에서 JEPA latent dynamics 가 일반화 최강.

### 4.3 stock Graph-JEPA 에서 가져올 것 (로컬 코드맵 결론)

`~/work/stock-v2-candidate-v17/stock_v2/graph_jepa.py` (순수 torch, PyG 비의존):
- **그대로 이식**: `GraphConvBlock`/`GraphEncoder`/`MLP`, `GraphBatch`+`merge_graph_batches`, EMA `update_target_encoder`, `_latent_regularizers`(VICReg), `_current_imputation_loss`+`imputation_standalone`(stage-1 생존 앵커), 마스크 샘플러 3종 — 특히 **`node_block`(노드 통째 마스킹)이 미관측 물체와 구조 동일**, `make_operational_feature_mask`(센서 결손 시나리오)도 관측 결손과 동형. 2-스테이지 동결 패턴(`run_real_backtest.py:2106-2119`, ~15줄).
- **재작성**: 피처/엣지 빌더 전부, 다운스트림 헤드 전부. `StockGraphJEPA` 클래스 통째 포팅 대신 JEPA 코어 ~600줄 추출.
- stock 에서 검증된 교훈 재활용: 2-스테이지 > joint (+31% IC), VICReg+imputation 앵커로 붕괴 해결, MPS fp32 제약.

### 4.4 리스크 (정직하게)

1. **supervised 가 이길 수 있다.** 시뮬에서는 GT 라벨이 공짜 → supervised TGN/DyGFormer + 범주형 헤드가 자연스럽고 강함. JEPA 의 존재 이유는 (i) 실로그(라벨 없음)에서 재관측-지연-라벨로 학습 가능, (ii) 위치 외 상태로 멀티태스크 확장, (iii) sim→real 전이. **A/B 를 처음부터 설계에 넣어야 함** (stock 에서 2-stage vs joint 를 A/B 했듯).
2. **last-seen + persistence 필터가 잔인하게 강한 베이스라인** (TGB 교훈 + 대부분 물체는 안 움직임). moved/stayed 층화 채점 없으면 무의미한 결과가 나옴.
3. JEPA implicit bias 로 인한 "불확실→누락" (§4.2) — multimodal readout 으로 완화하되, 그래프 상태추정에서 시연한 논문은 아직 없음 (우리가 검증하는 가설).
4. 시뮬 동역학의 리얼리즘 — 루틴 분포가 단조로우면 모델이 시간표 암기로 환원됨. HOMER-Noise/CASAS 캘리브레이션 + 환경·페르소나 랜덤화로 방어.

## 5. 실험 설계 v0 (초안 — 논의로 확정)

### 5.1 태스크/지표

- 에피소드 = 가구(집 레이아웃 + 물체 + 주민 N명 루틴) 며칠치. 관측 로그 = 사용자 에이전트 가시성 필터 통과 이벤트 (positive: o@r 관측, negative: r 봤는데 o 부재).
- 질의 세트 = (o, t) 샘플, o 는 t 에 미관측. **층화**: (i) 마지막 목격 후 위치 불변(stayed) vs 제3자 이동(moved), (ii) 미관측 경과 Δt 구간별.
- 지표: top-1/top-k 정확도, NDCG(SGM 호환), **Brier/Energy Score**(분포 채점), 기대 탐색 횟수(SGM 의 Find-Object), OSNOM 식 "소실 후 Δt 곡선". 헤드라인 = **moved 서브셋에서 last-seen 대비 우위 + stayed 서브셋 무손실 (칼리브레이션)**.

### 5.2 베이스라인 (전부 필수)

last-seen / 빈도 prior / 시간감쇠 persistence (Toris&Chernova) / Markov 전이 / SGM NEP 재구현 / supervised TGN·DyGFormer + 범주형 헤드 / GraphMAE 사전학습 비교 / LLM-with-log (이벤트 로그 텍스트化 → LLM 질의; 어시스턴트 실용 관점 대조군).

### 5.3 단계 (제안)

- **P0 설계 확정**: 스키마(노드/엣지/이벤트 vocabulary — VirtualHome 호환 권장), 생성기 스펙, 질의·지표 스펙. ← 지금 여기
- **P1 생성기 + 베이스라인**: 그래프 레벨 생성기 v0 → 비학습 베이스라인 4종 + supervised 1종. "문제가 학습으로 풀리는가 + 베이스라인 간격이 있는가" 확인. SGM 재현·확장에 해당.
- **P2 JEPA**: stock 코어 이식, JEPA vs supervised A/B, multimodal readout (범주형 probe → Branch-K) 실험.
- **P3 실데이터**: ADT 스티칭 평가, HD-EPIC/IT3DEgo zero-shot, (옵션) EgoLife 재주석.
- **P4+**: 픽셀→scene graph 지각 프론트엔드 (ProcTHOR 렌더 재생으로 GT 지도학습), 미래 상태 예측 확장.

지각 분리 논거: 모델 입력이 scene graph 로그이므로 P1–P3 는 지각 없이 성립. 픽셀 단계는 기존 검출기(+Lost&Found 식 업데이트)로 나중에 붙이는 게 리스크 격리에 유리.

### 5.4 하드웨어

그래프 레벨 모델(수백만~수천만 파라미터)은 이 iMac(MPS, fp32, batch 제약)으로 개발 루프 가능. 대규모 스윕만 RunPod/4090. OmniGibson 계열은 NVIDIA 전용이라 로컬 불가(어차피 미채택).

## 6. 결정 안건 (사용자와 확정할 것)

1. **데이터 전략**: 자체 그래프-레벨 생성기(HOMER 레시피 개조) 단독 vs DynamicTHOR 재활용 병행 vs 둘 다. — 내 추천: 자체 생성기 주력 + DynamicTHOR/HOMER+ 는 held-out 평가.
2. **출력 공간**: 방 수준 / **방×가구(receptacle) 계층** / 3D 좌표. — 추천: 계층 (SGM·HOMER 호환, 탐색 지표 자연스러움).
3. **방법 순서**: JEPA 먼저 vs supervised 먼저 vs **처음부터 A/B**. — 추천: A/B (P1 에 supervised 포함).
4. **multimodal readout**: 범주형 probe / 에너지 readout / Branch-K / Discrete latent. — 추천: 범주형 probe 로 시작, Branch-K 를 P2 ablation.
5. **벤치마크 야심**: 내부 실험용으로 충분 vs 공개 벤치마크化(논문 지향, EgoLife 재주석 포함 여부). — 스코프 결정 필요.
6. **1fps 지각 프론트엔드**: P4 로 미루는 분리안 동의 여부.
7. (부차) 시뮬 관측 모델 충실도: 가시성 필터를 방 단위로 단순화 vs FOV/거리/가림 모사 수준.
